# Immersive Technologies in Education and Professional Training: Bibliometric Pipeline

This repository contains the complete analytical workflow, preprocessing scripts, and classification logic for the bibliometric study: **"Immersive Technologies in Education and Professional Training: A Longitudinal Science-Mapping Review"**. 

The dataset encompasses both broad educational contexts and highly specialized professional training environments (such as clinical simulation and healthcare education), reflecting the prominent role these sectors have played in the adoption of Extended Reality (VR, AR, MR).

## 📋 Methodology & Pipeline Overview

The analysis is orchestrated by a central `main.py` script that ensures all modules operate on a unified, consistent dataset. The pipeline consists of three main stages:

### 1. Scopus Cleaning Pipeline (`utils/preprocess.py`)
To ensure methodological transparency, the pipeline automatically generates an audit trail (`pipeline_report.csv`) that details the document exclusion process:
1. **Raw Load**: Ingestion of the raw Scopus CSV export.
2. **Column Standardization**: Normalization of metadata fields.
3. **Exact Deduplication**: Removal of duplicate rows.
4. **DOI Deduplication**: Removal of records with identical DOIs.
5. **Title Deduplication**: Removal of records with highly similar titles.
6. **Missing Metadata**: Exclusion of records lacking essential fields (Title, Year, Source).
7. **Thematic & Temporal Screening**: Final filtering to ensure relevance and temporal bounds (1991–2025).

### 2. Technology & Orientation Classification (`utils/classifier.py`)
To avoid inconsistencies across different analyses, a single, canonical lexical classification function is applied to the corpus. The classifier evaluates the `Title`, `Abstract`, and `Author Keywords`.

* **Technology Categories:** Documents are classified into Virtual Reality (VR), Augmented Reality (AR), Mixed/Extended Reality (MR/XR), or Hybrid/Multi-technology based on explicit keyword occurrences. The hierarchy prioritizes cross-modality mentions (Hybrid) and explicit MR/XR terminology to prevent conflation.
* **Orientation (Technical vs. Pedagogical):** A purely lexical approach is used to determine the primary focus of the paper. This deterministic method avoids human coding bias. Due to the nature of the specific query used to extract the dataset, the lexical classifier naturally identifies the vast majority of the corpus (>99%) as pedagogically oriented. 

### 3. Analysis Modules (`src/`)
Each figure and table in the manuscript is generated by a specific, isolated module. This guarantees that parameters (e.g., fuzzy matching thresholds for keywords, community detection resolution) remain constant.
* **A1:** Publication Growth & Citation Evolution
* **A2b:** Hardware Triggers
* **A3:** Top Author Analysis (Productivity, Citations, H-index)
* **A4/A4b:** Country Collaboration (SCP vs MCP)
* **A5:** Bradford's Law & Source Analysis
* **A5b/A5c:** Keyword Co-occurrence Matrix & Semantic Landscape
* **A6:** Main Bibliometric Information Table
* **A7:** Author vs Index Keywords Comparison
* **A8:** Network Graphs (Keywords & Authors via Louvain community detection)

## 🚀 How to Run the Pipeline

### Prerequisites
* Python 3.9+
* Required libraries: `pandas`, `matplotlib`, `seaborn`, `networkx`, `python-louvain`, `thefuzz`

You can install the dependencies using:
```bash
pip install -r requirements.txt
```

### Execution
To run the complete pipeline and generate all tables and figures:

```bash
python main.py --input data/vr.csv --results-dir results/
```

You can optionally skip specific, time-consuming modules:
```bash
python main.py --input data/vr.csv --results-dir results/ --skip a5b,a8
```

## 🧮 Methodological Definitions & Formulas

To address potential ambiguities and ensure robust reproducibility, the following operational definitions and mathematical formulas are applied in our analysis.

### 1. Five-Category Technology Taxonomy

The classifier (`utils/classifier.py`) applies a deterministic, priority-ordered lexical rule to the concatenated `Title + Abstract + Author Keywords + Index Keywords` of each record. The five categories and their detection logic are:

| Category | Label | Detection logic | Example signals |
|---|---|---|---|
| **Virtual Reality** | `VR` | Exclusive VR signal, no AR/MR/XR | "virtual reality", "oculus", "HMD", "CAVE", "360° video" |
| **Augmented Reality** | `AR` | Exclusive AR signal, no VR/MR/XR | "augmented reality", "Google Glass", "marker-based", "mobile AR" |
| **Mixed Reality** | `MR` | Device-grounded MR signal (highest priority) | "mixed reality", "HoloLens", "Magic Leap", "spatial computing" |
| **Extended Reality** | `XR` | XR umbrella term without a more specific signal | "extended reality", " xr " |
| **Hybrid / Multi-technology** | `Hybrid` | Co-mention of VR **and** AR signals, without any MR or XR signal | Papers explicitly discussing or comparing both VR and AR |

#### Classification Priority Order
```
MR  →  XR  →  Hybrid (VR+AR)  →  AR  →  VR
```
MR is assigned first because its terms are device-grounded and highly specific. XR is second because it is a broad umbrella label that should only apply when no more precise signal exists. Hybrid captures cross-technology research without conflating it with the umbrella XR concept.

#### What is Hybrid and how does it differ?
`Hybrid/Multi-technology` captures studies that simultaneously employ or compare VR and AR within the same research context. Typical examples include:
- **Comparative studies**: "We evaluated VR vs. AR for surgical skill training..."
- **Multi-modal curricula**: "The course combined a VR simulation lab with AR-based anatomical overlays..."
- **Literature reviews**: Systematic reviews that evaluate evidence across both VR and AR without committing to a single modality.

The key distinction from `MR` and `XR` is conceptual: MR and XR are **specific technologies** with defined hardware paradigms and interaction models. Hybrid is a **pedagogical or methodological strategy** — the intentional use of more than one immersive technology — rather than a technology category in itself. A paper about HoloLens (which renders holograms over the real world) is `MR`; a paper that deploys both an Oculus headset and a mobile AR app in the same classroom study is `Hybrid`.

### 2. Empirical Corpus Breakdown (9,535 classified records)

The following metrics confirm that separating MR and XR is empirically justified, not merely terminological:

| Category | N | Total Citations | H-index | First Year | Annual Growth |
|---|---|---|---|---|---|
| VR | 6,302 | 145,340 | 141 | 1992 | 19.7% |
| AR | 1,951 | 42,065 | 93 | 1998 | 20.7% |
| MR | 487 | 10,115 | 47 | **2003** | 23.0% |
| XR | 176 | 1,381 | 18 | **2019** | **67.4%** |
| Hybrid/Multi-technology | 619 | 15,899 | 57 | 2000 | 17.7% |

> **Key finding**: XR as a term does not appear in the corpus until 2019 and shows a 67% annual growth rate — the highest of all categories — confirming it is a newly emerging discourse layer on top of the established MR community (active since 2003). Treating them as a single category would mask this important temporal dynamic.

### 3. Justification for Separating MR and XR
While Mixed Reality (MR, grounded in the strict Milgram-Kishino continuum, 1994) and Extended Reality (XR, a broader umbrella term) are distinct conceptual constructs, they were historically grouped in an earlier version of this pipeline. The current version separates them based on:
1. **Empirical evidence**: The corpus itself shows XR only emerges from 2019 onward, while MR has been present since 2003 — a 16-year gap that a merged category would obscure.
2. **Literature support**: As noted in recent meta-analyses (e.g., Mystakidis, 2022; Radianti et al., 2020), the two terms are used by overlapping but distinct communities.
3. **Reproducibility**: Keeping them separate makes the classification rule explicit and auditable (see `table_A10_classification_trace.csv`).

### 4. Collaboration Indicators (SCP & MCP)
Country collaboration is determined by parsing the institutional affiliation strings of all authors in a document.
* **SCP (Single Country Publication):** A document where all authors are affiliated with institutions located in the exact same country.
* **MCP (Multiple Country Publication):** A document where at least one co-author is affiliated with an institution located in a different country than the corresponding author.

### 5. Revealed Comparative Advantage (RCA)
To measure a country's specialization in a specific immersive technology (e.g., VR) relative to its overall output in the XR dataset, we use the RCA index. It is calculated as:

**RCA_ij = ( X_ij / X_j ) / ( X_i / X_total )**

*Where:*
* **X_ij** = Number of publications by country *i* in technology *j*.
* **X_j** = Total global publications in technology *j*.
* **X_i** = Total publications by country *i* across all technologies in the corpus.
* **X_total** = Total publications in the entire corpus.

*(An RCA > 1 indicates that the country is highly specialized in that specific technology compared to the global average).*
